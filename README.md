# Odin Recipes

## Description
A simple website to demonstrate basic HTML usage.

## Details
This site is my first attempt to write pure HTML to create a static website. It focuses on a number of basic HTML tags and attributes such as:
- Headers
- Paragraphs
- Anchors (links)
- Images
- Ordered and Unordered lists
- typographical symbols (quotes and ampersand)
- **Strong** and *Emphasis*
